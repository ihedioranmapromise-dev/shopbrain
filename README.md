# ShopBrain

Multi-store wholesale **money partner** demo.

- Owner home with live brief
- Staff actions stay **pending** until owner accepts
- **Voice notes** on proof + owner instruct flow
- Multi-store on one account
- Day brief

## Stack

Next.js 14 · Tailwind · lucide icons

## Run

```bash
npm install
npm run dev
```

Deploy on Vercel from this repo.

## Product

Setup is the paid service: stores, staff, approval rules, training.
Software feels like a partner; Promise installs it for the business.
